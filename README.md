FFXI Ashita v4 Addons

A collection of Ashita v4 addons created for Final Fantasy XI / HorizonXI.

Addons

BLUSpells
Blue Magic spell-learning tracker with search, filtering, sorting, mob families,
known/unknown status, customizable appearance, and persistent UI settings.

IzClock
Customizable Vana'diel clock with day, moon, upcoming elements, local time,
persistent positioning, and appearance controls.

AddonControlPanel
GUI for loading, unloading, reloading, and configuring Ashita addons.

ScrollingCombatLog
Personal scrolling combat text for outgoing/incoming damage, healing, spells,
abilities, skillchains, magic bursts, EXP, gil, skill-ups, and more.

Installation

Copy the desired addon folder into:

Ashita/addons/

Then load it in-game:

/addon load <addonname>
